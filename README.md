# WanLog

家族で犬のお世話状況・体調・しつけルールを共有するWebアプリです。

食事の重複、お世話の漏れ、家族ごとに異なるしつけ方法などを防ぎ、犬の変化を継続的に記録できることを目指しています。

## 制作背景

複数人で犬を世話していると、次のような問題が発生します。

- 誰がいつ食事やおやつを与えたか分からない
- 散歩や手入れを「誰かがやった」と思い、対応が漏れる
- 家族によってしつけの方法や指示が異なる
- 体調の記録が口頭やチャットに分散する
- 動物病院で症状の経過を正確に説明しにくい

これらの情報を一か所に集約し、家族全員が同じ情報を確認できるようにするため、本アプリを開発しています。

## 解決したい課題

- 食事やおやつの重複による肥満を防ぐ
- お世話の担当者を明確にし、対応漏れを減らす
- しつけ方法を家族内で統一し、犬の混乱を防ぐ
- 日々の体調変化を記録し、小さな変化への気づきを支援する
- 診察時に体調の経過を正確に伝えられるようにする

> このアプリは病気を診断するものではありません。気になる症状がある場合は、動物病院への相談を想定しています。

## 想定ユーザー

複数の家族で犬を世話している家庭を想定しています。

特に、次のような人を対象としています。

- 家族内でお世話の状況を共有したい人
- 食事やおやつの重複を防ぎたい人
- 犬の体調を継続的に記録したい人
- 家族でしつけ方法を統一したい人

## MVPで実装する機能

初期版では、家族内のお世話状況を共有する機能を中心に実装します。

- 犬のプロフィール登録
- 食事、おやつ、散歩、手入れの記録
- 記録した日時と担当者の表示
- 今日のお世話一覧
- お世話の完了・未完了管理
- 家族全員の記録履歴

## 今後追加したい機能

- 食欲、排泄、体重、症状などの体調記録
- 体重や体調変化のグラフ表示
- 家族共通のしつけルール管理
- 服薬やお世話のリマインダー
- 動物病院で提示する記録レポート
- 複数の犬の管理
- 写真の登録

## 技術選定理由

### Next.js

フロントエンドとサーバー処理を一つのプロジェクトで管理でき、個人開発でもWebアプリを構築しやすいため採用しました。

また、Reactを利用した画面開発に加えて、データ取得やルーティングなども学習できる点を重視しました。

### TypeScript

データの種類を型として定義し、実装時のミスを減らすため採用しました。

犬、お世話記録、ユーザーなどのデータ構造を明確にでき、コードの保守性を高められると考えています。

## 画面設計

Figmaを使用して、モバイルファーストで画面設計を行います。

設計時は次の点を重視します。

- スマートフォンから短時間で記録できること
- 最後に誰が食事を与えたかすぐ確認できること
- 未完了のお世話が分かりやすいこと
- ITに詳しくない人でも操作できること
- 状態を色だけで判断させないこと

## 工夫したい点

- 食事の重複を防ぐため、最後に記録した時刻と担当者をホーム画面に表示する
- スマートフォンから少ない操作で記録できるようにする
- 家族を責める表現を避け、協力しやすいUIにする
- 他の家族や家庭のデータを不正に閲覧・編集できないようにする
- 正常時だけでなく、データがない状態やエラー状態も設計する
